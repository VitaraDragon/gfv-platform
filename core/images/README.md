# Immagini per i moduli core

## Icona app (`icon-*.png`)

Marchio prodotto **GFV** (lettere su verde). Master: `icons/gfv-mark.svg`. Stesse taglie anche in `icons/` per il manifest PWA.

Non usare il volto di Tony come icona app / notifiche / favicon.

## Icona Tony

Solo widget chat (FAB e header):

- **Nome file**: `tony-icon.png`
- **Formato consigliato**: PNG con sfondo trasparente
- **Dimensioni consigliate**: 64x64 px o 128x128 px (verrà ridimensionata dal CSS)
